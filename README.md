# Linux Home Server

## Project Overview

This project is a Linux home server environment built with Rocky Linux 10.2.

The main goal of this project is to learn Linux system administration, web server management, networking, security, and DevOps fundamentals through hands-on practice.

## Technologies

- Rocky Linux 10.2
- Apache HTTP Server
- Git
- GitHub

## Current Progress

- Rocky Linux installed in VMware Fusion
- System updated
- Apache HTTP Server installed
- Apache service configured
- First HTML page created and published
- Git repository initialized
